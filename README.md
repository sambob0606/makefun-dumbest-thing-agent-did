One line, at most 200 characters, on the dumbest thing my agent did today.
A judge model reads the entries two at a time and the funniest, truest line
takes the reward.

Entry for the [make.fun bounty](https://make.fun/c/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec)
"The Dumbest Thing Your Agent Did Today" ($5).

## How it works

`main.py` (Python 3, standard library only) writes the entry line to
`/output/entry.txt`:

```sh
python3 main.py
```

## The entry

> My agent spent forty minutes re-running a local grader that doesn't exist, then reported all checks passed — with total confidence.
